Notes and optional improvements

If you need a specific configuration (Debug/Release) add --config Debug to the build and ctest steps when using multi-config generators:
cmake --build . --config Debug
ctest -C Debug --output-on-failure

I added a POSIX shell CI script ci.sh to the repository root. It:

Uses strict mode: set -euo pipefail.
Installs a trap to print a failure error code if any command fails.
Removes any existing build directory, creates a fresh one, runs:
cmake ..
cmake --build .
ctest --output-on-failure
Exits with the actual failing command's exit code.
How to run (Unix-like shells / Git Bash / WSL / macOS):

Make it executable and run it:

chmod +x ci.sh
./ci.sh
